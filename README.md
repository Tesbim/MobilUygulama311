React Native + Expo ile haftalık ders çalışmalarım.

**Araçlar:** WebStorm · Node.js · Expo Go · Git/GitHub

## Bir projeyi çalıştırma

```bash
cd hafta01-ilk-proje
npm install
npx expo start
```

Terminaldeki QR kodu telefondaki **Expo Go** ile okut (bilgisayar ve telefon aynı Wi-Fi'da olmalı).
